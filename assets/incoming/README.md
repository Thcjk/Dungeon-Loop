# Asset Pack hier ablegen

Lade dein **entpacktes** Asset Pack in diesen Ordner hoch (keine ZIP-Dateien).

## So geht's auf GitHub

1. Öffne: https://github.com/Thcjk/Dungeon-Loop/tree/main/assets/incoming
2. Klicke **Add file** → **Upload files**
3. Ziehe den **entpackten Ordner** oder alle Dateien hierher
   - z. B. `assets/incoming/mein-pack/sprite.png`
4. Unten **Commit changes** klicken
5. Schreib dem Cursor-Agent: *„Asset Pack liegt in `assets/incoming/mein-pack/`“*

## Tipps

- **PNG / JPG / JSON / WAV** funktionieren gut
- Große ZIPs zuerst lokal entpacken, dann die Dateien hochladen
- Optional: eine `info.txt` mit Pack-Name, Lizenz und kurzer Beschreibung dazu legen
- Der Agent baut die Assets danach ins Spiel ein

## Beispiel-Struktur

```
assets/incoming/
  mein-welt-pack/
    info.txt
    tiles/
      grass.png
      tree.png
    characters/
      hero.png
```
